about=Samples the raster pixels that fall inside each vector feature and turns
    them into spectral characteristics: per-band statistics, mean vector,
    covariance and histograms. Reference profiles can be built from the features
    of a class and stored in the project, after which every feature is scored
    against the profile of its own class by six similarity metrics (spectral
    angle, Mahalanobis distance with a chi-square p-value, per-pixel SAM, inlier
    fraction, Jeffries-Matusita distance, histogram intersection) and assigned a
    typicality of 1 (typical), 2 (doubtful) or 3 (atypical). Includes a batch run
    over a whole layer, a class separability matrix, and JSON/CSV export of
    everything it computes. Requires numpy and matplotlib.
